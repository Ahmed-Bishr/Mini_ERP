# Mini ERP

A lightweight Enterprise Resource Planning (ERP) system designed to streamline business operations and resource management.

## Overview

Mini ERP is a comprehensive solution for managing core business processes including inventory management, sales, procurement, accounting, and more. This system provides an intuitive interface for tracking organizational resources and improving operational efficiency.

## Features

- **Inventory Management**: Track and manage product inventory in real-time
- **Sales Module**: Process sales orders and manage customer relationships
- **Purchase Management**: Handle supplier orders and procurement workflows
- **Accounting**: Basic financial tracking and reporting
- **Dashboard**: Overview of key business metrics
- **Reporting**: Generate business reports and analytics

This project is built with modern web technologies to ensure scalability and maintainability.
